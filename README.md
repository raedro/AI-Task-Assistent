# AI Task Assistant

A lightweight personal task manager with an AI-ready architecture.

## MVP
- Add tasks with due date and priority
- Complete tasks
- Filter pending/completed tasks
- Persistent local storage
- Clean responsive dashboard

## Next phase
- AI natural-language task extraction
- Smart priority suggestions
- Calendar integration
- Authentication and cloud persistence
- Notifications

## Run
Open `index.html` in a browser. No build step is required for the initial MVP.
